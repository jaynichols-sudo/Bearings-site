How it works

Northfix for AI tools is a small helper, called a connector, that runs on your Mac. It speaks MCP, the Model Context Protocol, which Claude Desktop and many other AI apps use to connect to tools.

  1. You ask your AI app a question, like “Who do I know at DISA?”
  2. The AI app asks the Northfix connector on your Mac.
  3. The connector reads your Northfix files on that Mac and works out the answer with the same engine the apps use.
  4. It hands back only that answer. Your AI app does the rest: drafts the intro request, plans your week, preps you for the meeting.

Nothing goes to a Northfix server. There isn’t one in the picture.

Set it up

First, open Northfix on your Mac once, with iCloud Drive on, so your network is there. The Mac app is the same Northfix you use on iPhone and iPad.

Claude Desktop (easiest)

  1. Download northfix.mcpb.
  2. Double-click it. Claude Desktop opens and asks to install the Northfix extension.
  3. Click Install. Leave the folder setting empty unless your Northfix files are somewhere unusual.
  4. Start a new chat and ask “Who do I know at DISA?” The first time, Claude asks whether to allow the Northfix tool. Allow it.

To turn it off or remove it later, open Claude Desktop’s Settings, then Extensions.

Claude Desktop (config file)

If you’d rather not use the extension, or your organization manages extensions:

  1. Install Node.js 18 or later if you don’t have it.
  2. Download northfix-mcp.mjs and move it somewhere it can stay, such as ~/Applications/Northfix/.
  3. Open ~/Library/Application Support/Claude/claude_desktop_config.json and add:
{
  "mcpServers": {
    "northfix": {
      "command": "node",
      "args": ["/Users/you/Applications/Northfix/northfix-mcp.mjs"]
    }
  }
}

Change /Users/you to your own home folder. Quit and reopen Claude Desktop after saving. If Claude can’t find node, use its full path, such as /opt/homebrew/bin/node or /usr/local/bin/node. Run which node in Terminal to see yours.

Cursor and other AI apps

Any app that can start a local MCP server works the same way. In Cursor, add the same lines to ~/.cursor/mcp.json. In other apps, look for “MCP servers”, “connectors” or “tools” in settings, and add a local server with the command node and the path to northfix-mcp.mjs as its argument.

Some AI apps only connect to servers on the internet. This one stays on your Mac on purpose, so it needs an app that supports local servers.

Options

  • Another folder. Pass --data /path/to/folder, or set NORTHFIX_DATA, to read the network from a folder that holds network.json. By default the connector looks in Northfix’s iCloud Drive folder, then in the app’s own folder for when iCloud is off. macOS may ask once to allow access to the second one.
  • Free plan count. NORTHFIX_STATE sets where the free plan’s daily count is kept. The default is ~/Library/Application Support/Northfix AI/.

What it can do

Your AI app picks the right tool for your question. You don’t need to name them. They’re listed here so you know what’s possible.

Privacy

  • Answered on your Mac. The connector reads your Northfix files on your Mac and works out each answer there.
  • Nothing goes to Northfix. There’s no Northfix server involved, no account and no analytics.
  • Only agency names go to USASpending.gov. recompetes and teaming_partners ask USASpending.gov, the government’s public spending site, for contract awards. The request holds the agency name and dates, never anyone from your network. Every other tool makes no internet connections at all.
  • Your AI app sees only the answers to questions you ask. It never gets your whole network. What it does with an answer is up to that app’s own privacy policy. For example, Claude Desktop sends your chat, including these answers, to Anthropic so Claude can reply.
  • Read-only, except changes you approve. It never changes your network files directly. A note, call, follow-up or stage change you approve waits in a small file in your Northfix folder until the app files it, then the file is deleted. Nothing is ever sent to anyone.

Troubleshooting

It says it can’t find my network.

Open Northfix on the same Mac and leave it open for a minute so iCloud can download your network. Check that iCloud Drive is on in System Settings. Then ask again.

Claude doesn’t use the Northfix tools.

Check that Northfix shows as on in Claude Desktop’s Settings, under Extensions. Start a new chat after installing. Naming it helps too: “Using Northfix, who do I know at DISA?”

Claude says the server failed to start.

With the config file setup, Claude couldn’t run node. Put the full path to node in command, check the path to northfix-mcp.mjs, and reopen Claude Desktop. Node.js needs to be version 18 or later.

A note I saved isn’t in the app.

Notes are filed the next time Northfix opens on that Mac. Open it, and the note is filed on the person it names.

Recompetes or teaming partners come back empty.

Those two need an internet connection to reach USASpending.gov. When you don’t name an agency, recompetes looks at your watchlist and open pursuits, so name one if those are empty: “recompetes at DISA”.

Common questions

Does it see my LinkedIn messages?

Only what Northfix already has from your LinkedIn data download, and only to answer the question asked, such as when someone last wrote to you.

Does it work on Windows or Android?

Not yet. It reads the files the Mac, iPhone and iPad apps keep in iCloud Drive.

Can my whole team use it?

Yes. Each person runs it on their own Mac, against their own network. Teammates’ contacts show up in ways in and pipeline answers when you’re on a Northfix Team.
